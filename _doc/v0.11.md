# v0.11 - 特殊函數與進階ODE (2026-05-20)

## 完成功能

### 特殊函數
- [x] **Gamma** Γ(x) - Gamma 函數
- [x] **Beta** B(m, n) - Beta 函數
- [x] **Bessel** Jₙ(x) - Bessel 函數
- [x] **Legendre** Pₙ(x) - Legendre 多項式
  - Rodriguez 公式實現
  - 遞迴評估

### 進階微分方程
- [x] **可分離變數ODE** (solveSeparable)
  - `dy/dx = f(x)g(y)` → 分離變數後積分
- [x] **Bernoulli 方程** (solveBernoulli)
  - `y' + P(x)y = Q(x)yⁿ`
  - 變數變換為線性 ODE

## 使用範例

```typescript
import { Gamma, Beta, Bessel, Legendre, dsolve, Symbol, Integer, Add, Div } from 'sym4js'

const x = new Symbol('x')
const y = new Symbol('y')

// Gamma 函數
const g5 = new Gamma(new Integer(5))
console.log(g5.toString())  // Gamma(5)

// Beta 函數
const b = new Beta(new Integer(3), new Integer(4))
console.log(b.toString())  // Beta(3, 4)

// Legendre 多項式
const p2 = new Legendre(new Integer(2), x)
console.log(p2.toString())  // P_2(x)

// Legendre 數值評估
console.log(Legendre.evaluate(2, 0.5))  // -0.125

// 可分離 ODE
// dy/dx = x/y → y dy = x dx → y²/2 = x²/2 + C
// 需使用 dsolve 接口
```
