# v0.17 - 表達式剖析器與 TeX 支援 (Expression Parser & TeX)

## 目標

簡化 Sym4JS 的語法，使其更接近 SymPy 的簡潔風格，並支援 LaTeX 匯入/匯出：

```python
# SymPy
x, y = symbols('x y')
expr = (x + 2*y)**2
expand(expr)  # x**2 + 4*x*y + 4*y**2
```

```typescript
// Sym4JS (v0.17)
const [x, y] = symbols('x y')
const expr = parse('(x + 2*y)^2')
const expanded = expand(expr)

// LaTeX 匯出
expr.toLatex()  // "(x + 2y)^2"

// LaTeX 匯入
const latexExpr = texParse('\\frac{x^2 - 1}{x - 1}')
expand(latexExpr)  // x+1
```

## 功能規劃

### 1. symbols() - 批量創建符號
```typescript
symbols('x')           // → [Symbol('x')]
symbols('x y z')      // → [Symbol('x'), Symbol('y'), Symbol('z')]
symbols('x, y, z')     // → [Symbol('x'), Symbol('y'), Symbol('z')]
```

### 2. parse() - 表達式字串剖析
支援四則運算、指數、函數：
```
parse('x + 2*y')      // Add(x, Mul(2, y))
parse('x^2')          // Pow(x, 2)
parse('(x + y)^2')    // Pow(Add(x, y), 2)
parse('sin(x)')       // Sin(x)
parse('-x')            // Neg(x)
```

### 3. toLatex() - 匯出為 LaTeX
每個 Expression 實例方法：
```typescript
const x = new Symbol('x')
const expr = new Pow(new Add(x, new Integer(1)), new Integer(2))
console.log(expr.toLatex())  // "(x+1)^2"
```

完整對應表：
| Expression | LaTeX |
|------------|-------|
| `Integer(2)` | `2` |
| `Symbol('x')` | `x` |
| `Add(a, b)` | `a + b` |
| `Mul(a, b)` | `ab` 或 `a \cdot b` |
| `Pow(x, 2)` | `x^2` |
| `Pow(x, 3)` | `x^3` |
| `Pow(x, -1)` | `x^{-1}` |
| `Div(a, b)` | `\frac{a}{b}` |
| `Neg(x)` | `-x` |
| `Sin(x)` | `\sin x` |
| `Cos(x)` | `\cos x` |
| `Log(x)` | `\log x` |
| `Exp(x)` | `e^x` |
| `Sqrt(x)` | `\sqrt{x}` |
| `Gamma(x)` | `\Gamma(x)` |

### 4. texParse() - LaTeX 匯入
支援基本 LaTeX 數學語法：
```
texParse('x + y')           // Add(x, y)
texParse('\\frac{x}{y}')    // Div(x, y)
texParse('x^{2}')           // Pow(x, 2)
texParse('\\sqrt{x}')      // Sqrt(x)
texParse('\\sin(x)')        // Sin(x)
texParse('-x')              // Neg(x)
texParse('\\int x dx')      // Integrate(x, x) (未來)
```

### toLatex() 實現
在每個 Expression 類別新增 `toLatex()` 方法：
```typescript
class Integer {
  toLatex(): string {
    return this.value.toString()
  }
}

class Symbol {
  toLatex(): string {
    return this.name
  }
}

class Add {
  toLatex(): string {
    return this.args.map(a => a.toLatex()).join(' + ')
  }
}

class Mul {
  toLatex(): string {
    const terms = this.args.map(a => {
      if (a.type === 'add') return `(${a.toLatex()})`
      return a.toLatex()
    })
    return terms.join('')
  }
}

class Pow {
  toLatex(): string {
    const base = this.base.toLatex()
    const exp = this.exp.toLatex()
    if (this.exp.type === 'integer' && (this.exp as Integer).value === 1n) {
      return base
    }
    if (this.exp.type === 'integer' && (this.exp as Integer).value > 0n) {
      return `${base}^{${exp}}`
    }
    return `${base}^{${exp}}`
  }
}

class Div {
  toLatex(): string {
    return `\\frac{${this.numerator.toLatex()}}{${this.denominator.toLatex()}}`
  }
}

class Neg {
  toLatex(): string {
    return `-${this.arg.toLatex()}`
  }
}
```

### LaTeX 詞法分析
| Token | 類型 |
|-------|------|
| `+` | PLUS |
| `-` | MINUS |
| `*` | TIMES |
| `/` | DIV |
| `^` | POW |
| `(` `)` | LPAREN, RPAREN |
| `{` `}` | LBRACE, RBRACE |
| `\` | BACKSLASH |
| number | NUMBER |
| identifier | IDENT |
| `\frac` | FRAC |
| `\sqrt` | SQRT |
| `\sin`, `\cos`, etc. | FUNC |

### LaTeX 語法分析 (Pratt Parser)
```
expr     → term (('+' | '-') term)*
term     → factor (('*' | '/') factor)*
factor   → primary ('^' primary)*
primary  → NUMBER | IDENT | '(' expr ')' | '\frac' '{' expr '}' '{' expr '}' | '\sqrt' '{' expr '}' | FUNC '(' expr ')'
```

## 使用範例

```typescript
import { symbols, parse, texParse, expand, diff } from 'sym4js'

// 批量創建符號
const [x, y] = symbols('x y')

// 表達式解析
const expr1 = parse('(x + 2*y)^2')
console.log(expand(expr1).toString())
// x^2 + 4*x*y + 4*y^2

// LaTeX 匯出
console.log(expr1.toLatex())
// (x+2y)^2

// LaTeX 匯入
const expr2 = texParse('\\frac{x^2 - 1}{x - 1}')
console.log(expand(expr2).toString())
// x+1

// 微分並轉 LaTeX
const expr3 = parse('sin(x)')
const deriv = diff(expr3, x)
console.log(deriv.toLatex())
// \cos x

// 複雜表達式
const expr4 = parse('(exp(x) - 1) / x')
console.log(expr4.toLatex())
// \frac{e^x - 1}{x}
```
