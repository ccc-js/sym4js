# v0.4 - 方程求解 (2026-05-20)

## 完成功能

### 代數方程求解
- **solve** - 解代數方程式
  - 線性方程式：`ax + b = 0 → x = -b/a`
  - 二次方程式：基本根求解
  - 多項式因式分解後求解

### 線性方程組
- **solveLinearSystem** - 解線性方程組
  - 使用高斯消去法 (Gaussian elimination)
  - 支援 n×n 線性方程組
  - 範例：
    ```
    2x + y = 5
    x - y = 1
    → x = 2, y = 1
    ```

### 基本微分方程
- **solveODE** - 解基本一階微分方程
  - `dy/dx = ky → y = Ce^(kx)`
  - 分離變數法（基本形式）

## 使用範例

```typescript
import { Symbol, Integer, Add, Mul, Pow, solve, solveLinearSystem, solveODE } from 'sym4js'

const x = new Symbol('x')
const y = new Symbol('y')
const C = new Symbol('C')

// 代數方程求解
// 2*x + 3 = 0 → x = -3/2
const eq1 = new Add(new Mul(new Integer(2), x), new Integer(3))
const solutions = solve(eq1, x)

// 線性方程組
// 2x + y = 5, x - y = 1
const eq2 = new Add(new Mul(new Integer(2), x), y)
const eq3 = new Add(x, new Neg(y))
const solution = solveLinearSystem([eq2, eq3], [x, y])
// solution.get(x) = Integer(2), solution.get(y) = Integer(1)

// 基本微分方程
// dy/dx = 2y → y = Ce^(2x)
const dy = new Mul(new Integer(2), y)
const odeSolution = solveODE(dy, x)
// odeSolution = C * exp(2*x)
```

## 演算法說明

### 高斯消去法 (Gaussian Elimination)
1. 將方程組寫成增廣矩陣
2. 前向消去 (Forward elimination)
3. 向後替換 (Back substitution)

時間複雜度：O(n³)
