# v0.17.3 - 符號剖析與 Expand Bug 修復 (2026-05-19)

## 完成功能

### symbols() 支援空白分隔
```typescript
symbols('x', 'y', 'z')  // 原本用法
symbols('x y z')       // 新增：空白分隔
symbols('x, y, z')     // 新增：逗號分隔
```

### parse() - 表達式字串剖析
```typescript
parse('x + 2*y')       // Add(x, Mul(2, y))
parse('(x + y)^2')      // Pow(Add(x, y), 2)
parse('sin(x) + cos(x)') // Add(Sin(x), Cos(x))
parse('x^2 - y^2')      // Sub(Pow(x, 2), Pow(y, 2))
```

支援：
- 四則運算: `+`, `-`, `*`, `/`, `^`
- 括號分組: `(x + y)`
- 函數: `sin`, `cos`, `tan`, `exp`, `log`, `gamma`, `erf`, `psi`
- 數字: 整數
- 符號: 任意識別符

### texParse() - LaTeX 剖析
```typescript
texParse('\\frac{x^2 - 1}{x - 1}')  // Div(Sub(Pow(x, 2), 1), Sub(x, 1))
texParse('\\sin(x) + \\cos(x)')     // Add(Sin(x), Cos(x))
texParse('\\sqrt{x}')                // Pow(x, 1/2)
texParse('x + 2y')                   // x + 2*y (隱式乘法)
```

支援：
- `\frac{num}{den}` - 分數
- `\sqrt{x}` - 平方根
- `\sin`, `\cos`, `\tan`, `\exp`, `\log` 等函數
- 隱式乘法: `xy` = `x*y`
- LaTeX 命令: `\frac`, `\sqrt`, `\sin` 等

### toLatex() 改進
所有 Expression 類別都新增了 `toLatex()` 方法：
```typescript
const expr = parse('(x + y)^2')
console.log(expr.toLatex())  // (x+y)^{2}
```

## Bug 修復

### expand() 堆疊溢位問題
**問題**：
對某些複雜表達式（如 `\frac{x^2-1}{x-1}`）調用 `expand()` 時，會造成無窮遞迴導致堆疊溢位。

**修復方案**：
1. 添加 `MAX_EXPAND_DEPTH = 100` 限制遞迴深度
2. 在 `expandFraction` 中檢測潛在循環依賴
3. 對可能導致循環的表達式直接返回簡化形式

```typescript
// 受影響的表達式類型
// - \frac{...含有x的多項式}{...含有x的同類多項式}
// - 展開後結構與原始結構相同的表達式
```

**限制**：
部分代數分式（如 `\frac{x^2-1}{x-1}`）展開後只返回簡化形式，
而非完全展開的 `(x+1)(x-1)/(x-1)` = `x+1`。
這是因為完整代數餘式計算需要更複雜的 GCD/因式分解邏輯。

## 使用範例

```typescript
import { symbols, parse, texParse, expand, factor } from 'sym4js'

// symbols - 批量創建
const [x, y, z] = symbols('x y z')
const [a, b] = symbols('a, b')

// parse - 字串解析
const expr1 = parse('(x + y)^2')
console.log(expand(expr1).toString())
// x**2 + 2*x*y + y**2

const expr2 = parse('x^2 - y^2')
console.log(factor(expr2).toString())
// (x-y)*(x+y)

// texParse - LaTeX 解析
const expr3 = texParse('\\frac{x^2 - 1}{x - 1}')
console.log(expr3.toLatex())
// \frac{x^{2} - 1}{x - 1}

// 三角函數
const expr4 = texParse('\\sin(x) + \\cos(x)')
console.log(expr4.toLatex())
// \sin x + \cos x

// 開方
const expr5 = texParse('\\sqrt{x^2 + 1}')
console.log(expr5.toLatex())
// (x^{2} + 1)^{\frac{1}{2}}
```
