# v0.8 - 恆等式化簡與多項式根 (2026-05-20)

## 完成功能

### 恆等式化簡
- [x] **三角恆等式**
  - `sin²(x) + cos²(x) → 1`
- [x] **雙曲恆等式**
  - `cosh²(x) - sinh²(x) → 1`

### 三角函數微積分
- [x] **diff** 支援完整三角函數
  - `sin, cos, tan, cot, sec, csc`
  - `sinh, cosh, tanh`
  - `exp, log`
- [x] **integrate** 支援完整三角函數
  - `∫ sin(x) dx = -cos(x)`
  - `∫ cos(x) dx = sin(x)`
  - `∫ tan(x) dx = -ln|cos(x)|`
  - `∫ sec(x) dx = ln|sec(x) + tan(x)|`
  - `∫ csc(x) dx = -ln|csc(x) + cot(x)|`
  - `∫ sinh(x) dx = cosh(x)`
  - `∫ cosh(x) dx = sinh(x)`
  - `∫ tanh(x) dx = ln(cosh(x))`
  - `∫ exp(x) dx = exp(x)`
  - 鏈式法則支援

### 多項式根求解
- [x] **Poly.roots()** - 求多項式根
  - 二次方程式：求根公式
  - 一次方程式
  - 返回 bigint[]

## 技術變更

- 更新 `src/operations/simplify.ts` - 新增 sin²+cos², cosh²-sinh² 識別
- 更新 `src/operations/diff.ts` - 新增 cot, sec, csc, sinh, cosh, tanh, exp, log 微分
- 更新 `src/operations/integrate.ts` - 新增完整三角/雙曲積分（含鏈式法則）
- 更新 `src/polynomial/poly.ts` - 新增 roots() 方法

## 使用範例

```typescript
import { simplify, sin, cos, sinh, cosh, Poly, diff, integrate, Symbol, Integer, Add, Pow } from 'sym4js'

const x = new Symbol('x')

// 恆等式化簡
console.log(simplify(new Add(new Pow(sin(x), new Integer(2)), new Pow(cos(x), new Integer(2)))).toString())
// 輸出: 1

console.log(simplify(new Add(new Pow(cosh(x), new Integer(2)), new Neg(new Pow(sinh(x), new Integer(2)))).add(One)).toString()))
// 輸出: 1 (or just simplify the cosh²-sinh² part)

// 三角微分
console.log(diff(new Sin(x), x).toString())    // cos(x)
console.log(diff(new Cos(x), x).toString())     // -sin(x)
console.log(diff(new Tan(x), x).toString())    // tan(x)^2 + 1

// 三角積分
console.log(integrate(new Sin(x), x).toString())   // -cos(x)
console.log(integrate(new Exp(x), x).toString())    // exp(x)

// 多項式根
const p = new Poly([1n, 0n, -1n])  // x² - 1
console.log(p.roots())  // [1n, -1n]
```
