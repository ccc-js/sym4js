# v0.13 - Riccati 方程與特殊函數微積分 (2026-05-20)

## 完成功能

### Riccati 方程求解
- [x] **solveRiccati** - 二次 Riccati 方程 `y' = ay² + by + c` 求解器
  - 提取方程係數 a, b
  - 返回 Riccati 解的形式
- [x] **dsolve 更新** - 在現有 ODE 求解流程中整合 Riccati

### 特殊函數微分
- [x] **Gamma 微分**
  - `d/dx Gamma(x) = Gamma(x) * Psi(x)`
  - Psi(x) 以符號形式保留（digamma 函數）
- [x] **Bessel 微分**
  - `d/dx J_n(x) = J_{n-1}(x) - n/x * J_n(x)`
- [x] **Legendre 微分**
  - `d/dx P_n(x) = n * (x * P_{n-1}(x) - P_{n-2}(x)) / (x² - 1)`

### 特殊函數積分
- [x] **Gamma 積分**
  - 返回 `incomplete_gamma(x)` 形式
- [x] **Bessel 積分**
  - 返回 `integral_BesselJ(n, x)` 形式
- [x] **Legendre 積分**
  - `∫P_1(x)dx = x²/2`
  - `∫P_n(x)dx = 2n/(n²-1) * P_n(x) - 2/(n²-1) * P_{n-2}(x)` (n > 1)
  - 其他情況返回符號形式

## 使用範例

```typescript
import { diff, integrate, Gamma, Bessel, Legendre, Symbol, Integer, dsolve } from 'sym4js'

const x = new Symbol('x')

// Gamma 微分
console.log(diff(new Gamma(x), x).toString())
// Gamma(x) * Psi_x

// Bessel 微分
const j2 = new Bessel(new Integer(2), x)
console.log(diff(j2, x).toString())
// BesselJ(1, x) - 2/x * BesselJ(2, x)

// Legendre 微分
const p3 = new Legendre(new Integer(3), x)
console.log(diff(p3, x).toString())
// 3*(x*P_2(x) - P_1(x))/(x^2-1)

// Legendre 積分
console.log(integrate(new Legendre(new Integer(1), x), x).toString())
// x^2/2

// Riccati 方程
const y = new Symbol('y')
const riccatiSol = dsolve(new Add(diff(y, x), new Mul(new Integer(2), new Pow(y, new Integer(2)), x)))
console.log(riccatiSol?.method)
// riccati_quadratic
```
