# v0.1 - 初始版本 (2026-05-18)

## 完成功能

### 核心功能
- **Symbol 類別** - 符號變數建立，支援假設 (assumptions)
- **Integer 類別** - 大整數支援 (使用 BigInt)
- **Add 類別** - 加法表達式，支援項合併
- **Mul 類別** - 乘法表達式，支援指數合併 (x*x -> x**2)
- **Pow 類別** - 乘冪表達式
- **Neg 類別** - 負數表達式
- **Div 類別** - 除法表達式

### 操作功能
- **substitute** - 符號替換
- **simplify** - 表達式簡化

### Expression 界面
所有表達式都實現以下方法:
- `add(other)`, `sub(other)`, `mul(other)`, `div(other)`, `pow(other)`, `negate()`
- `equals(other)` - 表達式相等比較
- `toJSON()` - JSON 序列化
- `toString()` - 字串表示

## 使用範例

```typescript
import { Symbol, Integer, Add, Mul, Pow, substitute, simplify } from 'sym4js'

const x = new Symbol('x')
const y = new Symbol('y')

// 基本運算
const expr = x.add(y)  // x + y
const expr2 = x.mul(new Integer(2))  // 2*x
const expr3 = x.pow(new Integer(2))  // x**2

// 替換
const result = substitute(x.add(new Integer(1)), { variable: x, value: new Integer(2) })
// result = 3

// 簡化
// simplify(x.add(x)) // 待修復 - 無限迴圈
```

## 已知問題

1. **simplify(x+x)** - 會導致無限迴圈，需要修復 Add.flatten 的項合併邏輯
2. **符號假設** - 假設系統尚未完整實作
3. **缺乏工廠函數** - 目前需要直接使用 `new` 創建表達式
