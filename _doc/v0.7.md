# v0.7 - 函數化簡與特徵向量 (2026-05-20)

## 完成功能

### 函數化簡
- [x] **雙曲函數化簡**
  - `sinh(0) → 0`
  - `cosh(0) → 1`
  - `tanh(0) → 0`
  - `sinh(asinh(x)) → x`
  - `cosh(acosh(x)) → x`
  - `tanh(atanh(x)) → x`
- [x] **反雙曲函數化簡**
  - `asinh(sinh(x)) → x`
  - `acosh(cosh(x)) → x`
  - `atanh(tanh(x)) → x`
- [x] **反三角函數化簡**
  - `sin(asin(x)) → x`
  - `cos(acos(x)) → x`
  - `tan(atan(x)) → x`
  - `asin(sin(x)) → x`
  - `acos(cos(x)) → x`
  - `atan(tan(x)) → x`

### 特徵向量
- [x] **eigenvectors()** - 計算特徵向量
  - 2x2 矩陣封閉解
  - 返回 { eigenvalue, eigenvector } 陣列

## 使用範例

```typescript
import { simplify, sin, cos, sinh, cosh, Symbol, Poly, Integer, Add, Mul, Pow, Matrix } from 'sym4js'

const x = new Symbol('x')

// 反函數化簡
console.log(simplify(sin(new Asin(x))).toString())  // x
console.log(simplify(sinh(new Asinh(x))).toString())  // x

// 常數簡化
console.log(simplify(sin(new Integer(0))).toString())  // 0
console.log(simplify(cosh(new Integer(0))).toString())  // 1

// 多項式來自表達式
const expr = new Add(new Mul(new Integer(2), new Pow(x, new Integer(2))), x, new Integer(1))
const p = Poly.fromExpression(expr)
// p 代表 2x² + x + 1

// 特徵向量
const A = new Matrix([[new Integer(4), new Integer(2)], [new Integer(1), new Integer(3)]])
const eigenpairs = A.eigenvectors()
// 計算特徵值和對應特徵向量
```
