# v0.2 - 代數運算與微積分 (2026-05-19)

## 完成功能

### 代數運算
- **expand** - 代數展開
  - `(x+1)^2 → x^2 + 2x + 1`
  - `x*(a+b) → x*a + x*b`
  - 支援多項式展開

- **factor** - 因式分解（待完成）

### 微積分
- **diff** - 微分
  - `d/dx (x^2) = 2x`
  - `d/dx (sin(x)) = cos(x)`
  - `d/dx (cos(x)) = -sin(x)`
  - `d/dx (tan(x)) = 1 + tan^2(x)`
  - 支援高階微分

### 三角函數
- **Sin** - 正弦函數 `sin(x)`
- **Cos** - 餘弦函數 `cos(x)`
- **Tan** - 正切函數 `tan(x)`
- **Log** - 對數函數 `log(x)`
- **Exp** - 指數函數 `exp(x)`

## 使用範例

```typescript
import { Symbol, Integer, Add, Mul, Pow, expand, diff, Sin, Cos, Tan } from 'sym4js'

const x = new Symbol('x')

// 展開
const expr = new Pow(new Add(x, new Integer(1)), new Integer(2))
console.log(expand(expr).toString())  // x**2 + 2*x + 1

// 微分
const x2 = new Pow(x, new Integer(2))
console.log(diff(x2, x).toString())  // 2*x

// 三角函數微分
const sinX = new Sin(x)
console.log(diff(sinX, x).toString())  // cos(x)

const cosX = new Cos(x)
console.log(diff(cosX, x).toString())  // -sin(x)

// 高階微分
console.log(diff(x2, x, 3).toString())  // 0 (after simplify)
```
