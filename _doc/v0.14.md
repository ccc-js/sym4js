# v0.14 - Error Function 與初值問題 (2026-05-20)

## 完成功能

### Error Function (erf)
- [x] **Erf** - 誤差函數類
  - `erf(x) = 2/√π ∫₀ˣ e^{-t²} dt`
  - 級數展開可用於數值計算
- [x] **Erfc** - 互補誤差函數
  - `erfc(x) = 1 - erf(x)`
- [x] **Psi** - Digamma 函數
  - `ψ(x) = d/dx ln(Gamma(x))`

### 特殊函數微分
- [x] **erf 微分**: `d/dx erf(x) = 2/√π * e^{-x²}`
- [x] **erfc 微分**: `d/dx erfc(x) = -2/√π * e^{-x²}`
- [x] **psi 微分**: `d/dx psi(x) = 1/x`

### ODE 初值問題 (IVP) 支援
- [x] **dsolve with initialConditions**
  - `dsolve(equation, y, { initialConditions: Map })`
  - 支援 `y(x₀) = y₀` 形式的初值條件
  - 自動將通解中的常數 C 替換為滿足初值的特定值
- [x] **substituteConstant** - 常數替換輔助函數

## 使用範例

```typescript
import { dsolve, diff, Symbol, Integer, Erf, Erfc, Psi } from 'sym4js'

const x = new Symbol('x')
const y = new Symbol('y')

// erf 微分
console.log(diff(new Erf(x), x).toString())
// 2/sqrt_pi * e^(-x^2)

// erfc 微分
console.log(diff(new Erfc(x), x).toString())
// -2/sqrt_pi * e^(-x^2)

// psi 微分
console.log(diff(new Psi(x), x).toString())
// 1/x

// IVP: y' = y, y(0) = 1
const ic = new Map([[x, new Integer(0)], [y, new Integer(1)]])
const sol = dsolve(
  new Add(diff(y, x), createNeg(y)),
  y,
  { initialConditions: ic }
)
console.log(sol?.particular?.toString())
// 預期: e^0 = 1 (特定解)
```
