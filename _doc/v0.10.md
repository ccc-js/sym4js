# v0.10 - 進階微分方程與張量 (2026-05-20)

## 完成功能

### 微分方程符號求解
- [x] **dsolve** - 符號求解常微分方程
  - 一階線性ODE
  - 常係數線性ODE（特徵方程式）
  - 複數根處理

### 張量運算
- [x] **Tensor** 類別
  - 建立張量 (shape, rank)
  - 加法、減法、純量乘法
  - 張量積 (tensor product)
  - 收縮 (contraction)
  - 轉置 (2D)
  - 工廠方法：zeros, identity

### 級數運算
- [x] **summation** - 求和
  - 基本迭代計算
  - 符號表達式求值

## 使用範例

```typescript
import { dsolve, Tensor, summation, Symbol, Integer, Add, Mul, diff } from 'sym4js'

const x = new Symbol('x')
const y = new Symbol('y')

// 微分方程
// y'' - 2y' + y = 0
const eq = new Add(diff(y, x, 2), new Neg(new Mul(new Integer(2), diff(y, x))), y)
const solution = dsolve(eq, y)
// y = C1*e^x + C2*x*e^x

// 張量
const t = new Tensor([[1, 2], [3, 4]], [2, 2])
console.log(t.rank)     // 2
console.log(t.shape)    // [2, 2]
const doubled = t.scale(2)
const sum = t.add(new Tensor([[5, 6], [7, 8]], [2, 2]))
console.log(t.transpose().toString())

// 級數求和
const k = new Symbol('k')
console.log(summation(new Mul(k, k), [k, new Integer(1), new Integer(10)]))
// 55 (1+2+...+10 = 55)
```
