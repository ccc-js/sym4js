# v0.17.1 - LaTeX 匯出 (2026-05-19)

## 完成功能

### toLatex() - 表達式匯出為 LaTeX

每個 Expression 類別新增 `toLatex()` 方法，支援：

| Expression 類別 | LaTeX 輸出 |
|---------------|-----------|
| `Integer(n)` | `n` |
| `Symbol('x')` | `x` |
| `Add(a, b, ...)` | `a + b + ...` |
| `Mul(a, b, ...)` | `ab...` (數字在前面時分開) |
| `Pow(x, 2)` | `x^{2}` |
| `Pow(x, 3)` | `x^{3}` |
| `Pow(x, n)` | `x^{n}` |
| `Div(a, b)` | `\frac{a}{b}` |
| `Neg(x)` | `-x` |
| `Sin(x)` | `\sin x` |
| `Cos(x)` | `\cos x` |
| `Tan(x)` | `\tan x` |
| `Cot(x)` | `\cot x` |
| `Sec(x)` | `\sec x` |
| `Csc(x)` | `\csc x` |
| `Exp(x)` | `e^{x}` |
| `Log(x)` | `\log x` |
| `Asin(x)` | `\arcsin x` |
| `Acos(x)` | `\arccos x` |
| `Atan(x)` | `\arctan x` |
| `Sinh(x)` | `\sinh x` |
| `Cosh(x)` | `\cosh x` |
| `Tanh(x)` | `\tanh x` |
| `Gamma(x)` | `\Gamma(x)` |
| `Beta(x, y)` | `\mathrm{B}(x,y)` |
| `Bessel(n, x)` | `J_n(x)` |
| `Legendre(n, x)` | `P_n(x)` |
| `Erf(x)` | `\operatorname{erf}(x)` |
| `Erfc(x)` | `\operatorname{erfc}(x)` |
| `Psi(x)` | `\psi(x)` |

## 使用範例

```typescript
import { Symbol, Integer, Add, Mul, Pow, Neg, Div, Sin, Cos, Exp } from 'sym4js'

const x = new Symbol('x')
const y = new Symbol('y')

// 基本表達式
const expr1 = new Add(new Pow(x, new Integer(2)), new Integer(4))
console.log(expr1.toLatex())  // x^{2} + 4

// 分數
const expr2 = new Div(new Add(x, y), new Integer(2))
console.log(expr2.toLatex())  // \frac{x + y}{2}

// 三角函數
const expr3 = new Sin(x)
console.log(expr3.toLatex())  // \sin x

// 指數
const expr4 = new Exp(x)
console.log(expr4.toLatex())  // e^{x}

// 負數
const expr5 = new Neg(new Pow(x, new Integer(3)))
console.log(expr5.toLatex())  // -x^{3}

// 複雜表達式
const expr6 = new Pow(new Add(x, new Integer(1)), new Integer(2))
console.log(expr6.toLatex())  // (x+1)^{2}
```
