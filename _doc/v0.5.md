## 使用範例 (預期)

```typescript
import { Matrix, series, sin, cos, exp, x } from 'sym4js'

// 矩陣運算
const A = new Matrix([[1, 2], [3, 4]])
const B = new Matrix([[1, 0], [0, 1]])
console.log(A.add(B))  // [[2, 2], [3, 5]]
console.log(A.mul(B))  // 矩陣乘法
console.log(A.det())  // -2
console.log(A.inv())  // [[-2, 1], [1.5, -0.5]]

// 級數展開
console.log(series(exp(x), x, 0, 5))
// 1 + x + x²/2 + x³/6 + x⁴/24
```

## 技術難點

### 矩陣運算
- 行列式計算需要遞迴或 LU 分解
- 逆矩陣需要伴隨矩陣或高斯-喬登消去法
- 特徵值需要數值方法 (QR algorithm)

### 級數展開
- 符號微分需要多次計算導數
- 收斂半徑需要考慮奇點
- 拉格朗日餘項

## 優先順序

1. **矩陣基本運算** - 最實用
2. **反三角函數** - 常見需求
3. **雙曲函數** - 科學計算常用
4. **級數展開** - 理論基礎
