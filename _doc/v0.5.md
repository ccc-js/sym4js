# v0.5 - 函數與進階功能 (2026-05-20)

## 完成功能

### 初等函數
- [x] 完整三角函數庫
  - **Cot** - 餘切 `cot(x) = cos(x)/sin(x)`
  - **Sec** - 正割 `sec(x) = 1/cos(x)`
  - **Csc** - 餘割 `csc(x) = 1/sin(x)`
- [x] 反三角函數
  - **Asin** - 反正弦
  - **Acos** - 反餘弦
  - **Atan** - 反正切
- [x] 雙曲函數
  - **Sinh** - 雙曲正弦
  - **Cosh** - 雙曲餘弦
  - **Tanh** - 雙曲正切

### 矩陣運算
- [x] **Matrix** 類別
  - 建立矩陣
  - 矩陣加法、減法、乘法
  - 轉置 (transpose)
  - 行列式計算 (det)
  - 逆矩陣 (inv)
  - 工廠方法：identity(n), zeros(rows, cols)

### 級數展開
- [x] **series** - 級數展開
  - 泰勒級數 (Taylor series)
  - 馬克勞林級數 (Maclaurin series)
  - 範例：`e^x = 1 + x + x²/2! + x³/3! + ...`

## 使用範例

```typescript
import { Matrix, series, taylor, maclaurin, Symbol, Exp } from 'sym4js'

const x = new Symbol('x')

// 矩陣運算
const A = new Matrix([[new Integer(1), new Integer(2)], [new Integer(3), new Integer(4)]])
const B = new Matrix([[new Integer(1), new Integer(0)], [new Integer(0), new Integer(1)]])
console.log(A.add(B))  // [[2, 2], [3, 5]]
console.log(A.mul(B))  // 矩陣乘法
console.log(A.det())  // -2
console.log(A.inv())  // 逆矩陣

// 級數展開
console.log(maclaurin(new Exp(x), x, 5))
// 1 + x + x²/2 + x³/6 + x⁴/24 + x⁵/120

console.log(taylor(new Exp(x), x, new Integer(1), 3))
// 在 x=1 處的泰勒展開
```

### 矩陣運算
- 行列式計算：遞迴展開（拉普拉斯展開）

- 在指定點代入計算係數
