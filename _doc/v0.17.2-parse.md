# v0.17.2 - 表達式剖析器 (Expression Parser)

## 目標

簡化 Sym4JS 的語法，使其更接近 SymPy 的簡潔風格：

```python
# SymPy
x, y = symbols('x y')
expr = (x + 2*y)**2
expand(expr)  # x**2 + 4*x*y + 4*y**2
```

```typescript
// Sym4JS (v0.17.2)
const [x, y] = symbols('x y')
const expr = parse('(x + 2*y)^2')
const expanded = expand(expr)
```

## 待完成功能

### 1. symbols() - 批量創建符號
```typescript
symbols('x')           // → [Symbol('x')]
symbols('x y z')        // → [Symbol('x'), Symbol('y'), Symbol('z')]
symbols('x, y, z')      // → [Symbol('x'), Symbol('y'), Symbol('z')]
```

### 2. parse() - 表達式字串剖析

支援四則運算：
```
parse('x + 2*y')       // Add(Symbol('x'), Mul(Integer(2), Symbol('y')))
parse('x - 2*y')       // Sub(Symbol('x'), Mul(Integer(2), Symbol('y')))
parse('x * 2*y')        // Mul(Symbol('x'), Integer(2), Symbol('y'))
parse('x / 2*y')        // Div(Symbol('x'), Integer(2))
parse('x^2')            // Pow(Symbol('x'), Integer(2))
parse('(x + y)^2')      // Pow(Add(Symbol('x'), Symbol('y')), Integer(2))
parse('-x')             // Neg(Symbol('x'))
```

支援函數：
```
parse('sin(x)')        // Sin(Symbol('x'))
parse('cos(x)')        // Cos(Symbol('x'))
parse('exp(x)')        // Exp(Symbol('x'))
parse('log(x)')        // Log(Symbol('x'))
parse('gamma(x)')      // Gamma(Symbol('x'))
```

支援特殊常數：
```
parse('pi')            // Symbol('pi')
parse('e')             // Symbol('e')
```

### 3. TeX 剖析器 (texParse) - 可選
```
texParse('x + y')            // Add(x, y)
texParse('\\frac{x}{y}')     // Div(x, y)
texParse('x^{2}')             // Pow(x, 2)
texParse('\\sqrt{x}')         // Sqrt(x)
texParse('\\sin(x)')          // Sin(x)
```

### 運算子優先級
```
highest:   ^ (pow)
           * /
           + -
lowest:    ()
```

### 詞法分析 (Lexer)
| Token | 類型 |
|-------|------|
| `+` | PLUS |
| `-` | MINUS |
| `*` | TIMES |
| `/` | DIV |
| `^` | POW |
| `(` `)` | LPAREN, RPAREN |
| number | NUMBER |
| identifier | IDENT |

### 語法分析 (Parser) - 遞迴下降
```
expression → term (('+' | '-') term)*
term       → factor (('*' | '/') factor)*
factor     → primary ('^' primary)*
primary    → NUMBER | IDENT | '(' expression ')'
```

## 使用範例

```typescript
import { symbols, parse, expand, factor, diff, texParse } from 'sym4js'

// 批量創建符號
const [x, y] = symbols('x y')

// 表達式解析
const expr1 = parse('(x + 2*y)^2')
console.log(expand(expr1).toString())
// x^2 + 4*x*y + 4*y^2

const expr2 = parse('x^2 - y^2')
console.log(factor(expr2).toString())
// (x-y)*(x+y)

// 微分
const expr3 = parse('sin(x)')
console.log(diff(expr3, x).toString())
// cos(x)

// LaTeX 解析 (未來)
const latexExpr = texParse('\\frac{x^2 - 1}{x - 1}')
console.log(expand(latexExpr).toString())
// x+1
```
