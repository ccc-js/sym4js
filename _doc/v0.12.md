# v0.12 - 特殊函數化簡與PDE基礎 (2026-05-20)

## 完成功能

### 特殊函數化簡
- [x] **Gamma 化簡**
  - `Gamma(n) → (n-1)!` (n 為正整數 1-20)
- [x] **Legendre 化簡**
  - `P_0(x) → 1`
  - `P_1(x) → x`
  - `P_2(x) → (3x²-1)/2`
  - `P_3(x) → (5x³-3x)/2`
  - `P_n(1) → 1`
  - `P_n(-1) → (-1)^n`

### 偏微分方程 (PDE) 基礎
- [x] **pdesolve** - 偏微分方程求解
  - Laplace 方程 ∇²φ = 0
  - 波動方程
  - 熱傳導方程
- [x] **separationOfVariables** - 分離變數法框架

## 使用範例

```typescript
import { simplify, Gamma, Legendre, pdesolve, Symbol, Integer } from 'sym4js'

const x = new Symbol('x')

// Gamma 化簡
console.log(simplify(new Gamma(new Integer(5))).toString())
// 24 (4!)

// Legendre 化簡
console.log(simplify(new Legendre(new Integer(0), x)).toString()
// 1

console.log(simplify(new Legendre(new Integer(1), x)).toString()
// x

console.log(simplify(new Legendre(new Integer(2), x)).toString()
// (3*x^2-1)/2

// PDE 求解
const y = new Symbol('y')
const t = new Symbol('t')
const phi = new Symbol('phi')

const laplaceSol = pdesolve(
  new Add(diff(phi, x, 2), diff(phi, y, 2)),
  phi,
  [x, y]
)
```
