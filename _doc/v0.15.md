### 邊值問題 (BC) 求解
- [x] **BoundaryConditions 介面**
  - `x0`, `y0` - 起始邊界點
  - `x1`, `y1` - 結束邊界點（可選）
- [x] **dsolve with boundaryConditions**

### 級數展開增強
- [x] **erf 級數展開**

- [x] **erfc 級數展開**
  - `erfc(x) = 1 - erf(x)`

### 數值計算模組

  - 支援特殊函數：erf, erfc, gamma, psi, bessel, legendre
  - 可配置精度和最大迭代次數
- [x] **Gamma 函數** - Lanczos 近似
- [x] **Digamma 函數** - 級數展開
- [x] **Bessel J_n(x)** - 遞推公式
- [x] **Legendre P_n(x)** - 遞推公式

## 使用範例

```typescript
import { series, evaluate, Erf, Symbol, dsolve, createNeg } from 'sym4js'

const x = new Symbol('x')

// erf 級數展開
console.log(series(new Erf(x), x).toString())
// 2/sqrt_pi * (x - x^3/3 + x^5/10 - ...)

// 數值評估
const vars = new Map([[x, 1.5]])
console.log(evaluate(new Erf(x), vars))
// 約 0.966105

// 邊值問題
const y = new Symbol('y')
const bcSol = dsolve(
  new Add(diff(y, x, 2), y),
  y,
  {
    boundaryConditions: {
      x0: new Integer(0),
      y0: new Integer(0),
      x1: new Integer(1),
      y1: new Integer(1)
    }
  }
)
console.log(bcSol?.method)
// linear_second_order_with_bc
```
