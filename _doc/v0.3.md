# v0.3 - 因式分解、積分與極限

## 規劃目標

完成代數運算與微積分的最後幾個核心功能。

## 待完成功能

### 代數運算
- [ ] **factor** - 因式分解
  - 多項式因式分解
  - 支援 `(x^2 - 1) → (x-1)(x+1)`
  - 參考 SymPy: `sympy/polys/polytools.py`

### 微積分
- [ ] **integrate** - 積分
  - 不定積分：`∫x^2 dx = x^3/3`
  - 定積分：`∫0^1 x dx = 1/2`
  - 參考 SymPy: `sympy/integrals/integrals.py`

- [ ] **limit** - 極限
  - `lim(x→0) sin(x)/x = 1`
  - 參考 SymPy: `sympy/series/limits.py`

### 三角函數擴展

  - **Sec** - 正割 `sec(x)`
  - **Csc** - 餘割 `csc(x)`

### 改進 diff
- [ ] 改進 `diff` 的簡化邏輯
- [ ] 支援更多函數的微分

## 技術難點

### factor (因式分解)
- 需要多項式除法
- 需要因式搜尋演算法
- 複雜度較高，需要謹慎實作

### integrate (積分)
- 需要模式匹配
- 需要處理不定積分 vs 定積分
- 需要常數處理

### limit (極限)
- 需要級數展開
- 需要處理各種不定型 (0/0, ∞/∞, 等)

## 使用範例 (預期)

```typescript
import { Symbol, Integer, Add, Mul, Pow, factor, integrate, limit, x } from 'sym4js'

// 因式分解
factor(x**2 - 1)  // (x-1)(x+1)

// 積分
integrate(x**2, x)  // x**3/3
integrate(x**2, [x, 0, 1])  // 1/3

// 極限
limit(sin(x).div(x), x, Zero)  // 1
```
