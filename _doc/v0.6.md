# v0.6 - 線性代數與函數擴展 (2026-05-20)

## 完成功能

### 反雙曲函數
- [x] **asinh** - 反雙曲正弦 `arsinh(x) = ln(x + sqrt(x² + 1))`
- [x] **acosh** - 反雙曲餘弦 `arcosh(x) = ln(x + sqrt(x² - 1))`
- [x] **atanh** - 反雙曲正切 `artanh(x) = (1/2)ln((1+x)/(1-x))`

### 矩陣進階運算
- [x] **LU 分解**
  - Doolittle 算法
  - 返回 { L, U } 矩陣
- [x] **QR 分解**
  - Gram-Schmidt 正交化
- [x] **特徵值** (限 2x2, 3x3 矩陣)
  - 二次方程式求根公式
  - 三次方程式數值解

### 多項式系統
- [x] **Poly** 類別 - 多項式表示
  - 係數向量表示 (bigint[])
  - 加法、減法、乘法
  - 除法（商和餘數）
  - 最大公因數 (gcd)
  - 最小公倍數 (lcm)
  - 導數、積分
  - 轉換為 Expression

## 使用範例

```typescript
import { Matrix, Poly, Symbol, Integer, Asinh, Acosh, Atanh } from 'sym4js'

const x = new Symbol('x')

// 反雙曲函數
console.log(new Asinh(x).toString())  // asinh(x)
console.log(new Acosh(x).toString())  // acosh(x)
console.log(new Atanh(x).toString())  // atanh(x)

// 矩陣 LU 分解
const A = new Matrix([[new Integer(2), new Integer(1)], [new Integer(1), new Integer(3)]])
const { L, U } = A.lu()

// 矩陣 QR 分解
const { Q, R } = A.qr()

// 矩陣特徵值
const B = new Matrix([[new Integer(4), new Integer(2)], [new Integer(1), new Integer(3)]])
const eigenvals = B.eigenvalues()

// 多項式運算
const p1 = new Poly([1n, 0n, -1n])  // x² - 1
const p2 = new Poly([1n, -1n])      // x - 1
console.log(p1.add(p2))             // x² + x - 2
console.log(p1.mul(p2))             // x³ - x² - x + 1
console.log(p1.gcd(p2))             // x - 1
console.log(p1.derivative())       // 2x

// 轉換為 Expression
console.log(p1.toExpression())      // x² - 1
```

## 演算法說明

### QR 分解 (Gram-Schmidt)
1. 取第一列為 q₁
2. 對每列减去其在已計算q上的投影
3. 正規化

### Polynomial GCD
- 使用歐幾里得算法
- `gcd(a, b) = gcd(b, a mod b)`
